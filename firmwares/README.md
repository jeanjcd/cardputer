# firmwares

Firmwares próprios para o Cardputer-Adv. Cada um fica numa subpasta com o mesmo nome do `.bin`, e o `.bin` pronto para o M5Launcher fica em `bin/`.

| Firmware | O que faz |
|---|---|
| [`m5-keyboard-macro/`](m5-keyboard-macro/) | Teclado + mouse Bluetooth com macro em loop: 3 movimentos aleatórios + 10× Shift a cada 60 s |
| [`m5-mesh-hello/`](m5-mesh-hello/) | Nó Meshtastic mínimo com o Cap LoRa-1262: lista de nós, DMs com PKI, canal público e saudação automática (uma vez por nó) |
