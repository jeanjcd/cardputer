# M5-Mesh-Hello

**M5Stack Cardputer-Adv** と **Cap LoRa-1262** で動く、小さな自己完結型の [Meshtastic](https://meshtastic.org) 互換ノードです。通常のノードとして Meshtastic ネットワークに参加し（デフォルト名は **4stro-031** / **4S31**）、周囲のノードを一覧表示し、暗号化されたダイレクトメッセージでやり取りし、公開チャンネル LongFast の読み書きができます。また、新しいノードそれぞれに**一度だけ**あいさつを送ることもできます。スマートフォンは不要です。

これは公式の Meshtastic ファームウェアではありません。ゼロから書かれた最小限の実装（RadioLib + プロトコル + 暗号）で、独自のキーボード UI を備え、M5Launcher で他のアプリと並べてインストールできるほど小さくなっています。

画面の表示はポルトガル語です。このドキュメントでは画面上の文字列を表示どおりに引用し、その意味を日本語で説明します。

> **日本でお使いの方へ（必ずお読みください）**
>
> - 日本向けのリージョンは **JP** で、LongFast の周波数は **923.375 MHz** です。これは Cap LoRa-1262 の M5Stack 定格（868–923 MHz）をわずかに超えるため、JP は**実験的**リージョンです。この周波数での性能は測定されていません。
> - JP の送信出力は、日本の規制に合わせてリージョンテーブルで **13 dBm** に制限されます。Config 画面で 22 dBm を設定しても、実際に使われる出力（実効出力）は 13 dBm です。
> - 日本国内で無線機器を使うには、**電波法**を守り、**技術基準適合証明等（技適）を受けた機器**を使う必要があります。**Cap LoRa-1262 が技適を取得しているかどうかは、利用者ご自身で確認してください。** 本プロジェクトは、このモジュールが技適を取得していると主張するものではありません。
> - このファームウェアは、日本の 920 MHz 帯の技術基準（ARIB STD-T108 など。キャリアセンスや送信時間に関する要件を含みます）への適合について評価されておらず、キャリアセンス（LBT）も実装していません。
> - **法令の遵守は利用者の責任です。** 詳しくは [docs/ja/frequencies.md](docs/ja/frequencies.md#実験的リージョン) を参照してください。

## 機能

- デフォルトの公開チャンネルで Meshtastic **LongFast** を使用（AES-128-CTR、デフォルト鍵）。
- 配信確認（ACK）付きの**暗号化ダイレクトメッセージ**（PKI: X25519 + SHA-256 + AES-256-CCM）。
- 名前、ハードウェアモデル、RSSI、最終受信からの経過時間、未読マーカー、あいさつ済みマーカーを表示する**ノード一覧**。
- **公開チャンネル**でのチャット。
- **自動あいさつ**: 起動するたびにオフになります。オンにすると、各ノードにあいさつ文を一度だけ（記録は永続化され、二度と送りません）、最大で 30 秒に 1 件送ります。
- **18 リージョン**（Cap の定格帯域内の 11 リージョンと、実験的な 7 リージョン）。送信出力は各リージョンの上限に制限され、デューティサイクル制限のあるリージョンでは 1 時間あたりの送信時間（エアタイム）の予算が適用されます。
- ロングネーム／ショートネーム、あいさつ文、送信出力を編集できます。鍵ペアはハードウェアのエントロピーから一度だけ生成され、NVS に保存されます（NVS が消去された場合にのみ変わります）。
- 他のノードのトラフィックを中継しません（`CLIENT_MUTE`）。Wi-Fi と Bluetooth はオフのままです。
- 移植性のあるプロトコルコアに、ネイティブ単体テスト、ファジングテスト、ASan/UBSan、CodeQL を CI で適用しています。

## ハードウェア

- **M5Stack Cardputer-Adv**（初代 Cardputer には対応していません）。
- **M5Stack Cap LoRa-1262**（SX1262、定格 868–923 MHz、最大 22 dBm）。
- Cap の RP-SMA コネクタに取り付ける**アンテナ**。キット付属のアンテナは 868 MHz に調整されており、902–928 MHz のリージョンでも約 0.5–2 dB の損失で使えます。これらのリージョンでは 915 MHz 用のアンテナのほうが適しています。

> **電源を入れる前に、必ずアンテナをねじ込んで取り付けてください。** ファームウェアは起動直後に NodeInfo を送信します。アンテナなしで送信すると無線部が損傷するおそれがあります。

詳細: [docs/ja/hardware.md](docs/ja/hardware.md)

## クイックスタート

1. [`bin/`](bin/) にあるリリースイメージを**検証**します。
   ```sh
   cd bin && sha256sum -c SHA256SUMS
   ```
2. `bin/M5-Mesh-Hello.bin` を microSD カードにコピーし、**M5Launcher** でインストールします。古いバージョンがインストールされている場合は、先に削除してください（**PMan → Remove**）。
   （`bin/M5-Mesh-Hello-merged.bin` は esptool でアドレス `0x0` に書き込むフルフラッシュイメージです。これを書き込むと **M5Launcher と、それを通じてインストールしたすべてのアプリが消去されます**。M5Launcher を使わない場合にのみ使用してください。）
3. アンテナを取り付けてアプリを起動します。初回起動時に鍵ペアが作成され、**リージョン**の選択を求められます（ANZ が選択済み。`;` / `.` で変更、`Enter` で確定）。日本では **JP**（実験的）を選んでください。**確定するまで何も送信されません。** 確定後、自身をアナウンスして受信を開始します。
4. リージョンは後から **Config** 画面（`Região`）で変更できます。すべてのノードが同じリージョンを使う必要があり、また、お住まいの国で合法なリージョンを使わなければなりません。
5. **Nós** 画面にノードが表示されるのを待ち、1 つ選んで `Enter` を押し、あらかじめ入力されたあいさつ文を送信します。または `A` を押して自動あいさつをオンにします。

## リージョン

デフォルトは **ANZ**（919.875 MHz）で、ブラジルの Meshtastic コミュニティが使っているリージョンです。ブラジルの公式 Meshtastic リージョンは BR_902（903.875 MHz）です。ファームウェアは US、EU_868、RU、KR、UA_868、MY_919、SG_923、PH_868、PH_915 にも対応し、さらに実験的な IN、NZ_865、NP_865、KZ_863、JP、TW、TH（Cap の定格帯域からわずかに外れる）にも対応しています。**必ず、今いる国のリージョンを使ってください。** 日本では JP（923.375 MHz、実験的、最大 13 dBm）です。リージョンの一覧表、周波数の計算式、出力の上限、デューティサイクルについては [docs/ja/frequencies.md](docs/ja/frequencies.md) を参照してください。

## ステータス

**v0.1.0。** Cardputer-Adv + Cap LoRa-1262 で実地テスト済みです。無線の初期化、送信、再起動をまたいだ識別情報の保持、UI 全体（画面、ナビゲーション、自動あいさつの切り替え）が動作します。**他の Meshtastic ノードとのエンドツーエンドのやり取り（実地で相手の NodeInfo、DM、ACK を受信すること）はまだ確認されていません。** テスト中に通信範囲内にノードがなかったためです。プロトコルは公式ファームウェアに基づいて実装され、参照ベクタでテストされていますが、動作報告があるまでは相互運用性は未確認とみなしてください。報告を歓迎します。
