## [0.1.0] - 2026-11-18

First public release.

### Added

- Meshtastic-compatible node for the M5Stack Cardputer-Adv with the Cap
  LoRa-1262 (SX1262): LongFast preset (BW 250 kHz, SF 11, CR 4/5, sync word
  0x2B), role `CLIENT_MUTE`, hop limit 3 on everything it originates.
- Region table with the Meshtastic frequency formula: ANZ (default, 919.875
  MHz), BR_902, US, EU_868, RU, KR, UA_868, MY_919, SG_923, PH_868, PH_915,
  plus experimental IN, NZ_865, NP_865, KZ_863, JP, TW and TH; TX power clamped
  to the region limit and the radio maximum; hourly duty-cycle airtime budget
  for regions that require it.
- Public channel (default key) with AES-128-CTR; direct messages with PKI
  (X25519 + SHA-256 + AES-256-CCM); ACK/NAK handling; first-key-wins storage
  of peer public keys.
- Keypair generated once from hardware entropy and stored in NVS; secrets are
  zeroized after use and never shown (only the public key fingerprint).
- Four screens (Nodes, Chat, Channel, Config) with keyboard navigation; UTF-8
  messages sent exactly as typed.
- Auto-greeter: off at boot, greets each node at most once (greeted set
  persisted, up to 500), at most one greeting every 30 s, queue of 10.
- Node database (100 nodes in RAM), up to 50 peers persisted, 30 messages per
  conversation, duplicate suppression of the last 64 `(from, id)` pairs.
- Release images `bin/M5-Mesh-Hello.bin` (M5Launcher) and
  `bin/M5-Mesh-Hello-merged.bin` (full image at 0x0), with `bin/SHA256SUMS`.
- Portable protocol core (`src/mesh/`) with native Unity tests, reference
  vectors generated by `tools/gen_vectors.py`, a 200,000-iteration fuzz-style
  test of the receive path, and an ASan/UBSan test environment.
- GPL-3.0-or-later license, third-party notices, security policy,
  contribution guide, CI (tests, sanitizers, device build, checksums), CodeQL
  and Dependabot configuration.
