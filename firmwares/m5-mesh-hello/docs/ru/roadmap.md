# Планы и известные ограничения

v0.1.0 — намеренно небольшой узел Meshtastic. На этой странице перечислено, чего он пока не умеет, идеи для v2 и известные ограничения v1. Ни одна из идей не является обещанием. Помощь приветствуется (см. [CONTRIBUTING.md](../../CONTRIBUTING.md), на английском).

## Идеи для v2

| Идея | Примечания |
|---|---|
| **GPS / местоположение** | Использовать GNSS ATGM336H на Cap (UART, ESP RX G15 / TX G13), чтобы отправлять `POSITION_APP` и показывать расстояние до других узлов. Передача LoRa мешает GNSS-приёмнику, поэтому их работу нужно аккуратно разносить по времени. |
| **Больше каналов и собственные PSK** | Дополнительные каналы, собственные ключи, каналы AES-256-CTR (32-байтовые PSK), имена каналов кроме `LongFast` и импорт URL/QR каналов. Сейчас поддерживается только основной канал по умолчанию, а `ctrCrypt` умеет только AES-128. |
| **Другие пресеты** | LongSlow, MediumFast, ShortFast и остальные пресеты модема (формула частоты уже учитывает имя канала и ширину полосы). |
| **Подпись и проверка XEdDSA** | Подписывать свои пакеты и проверять подписанные пакеты других, как это делают новые версии прошивки Meshtastic. |
| **Роль ретранслятора / маршрутизатора** | По желанию пересылать пакеты других узлов (обработка лимита хопов, маршрутизация next-hop) вместо `CLIENT_MUTE`. |
| **Повтор личных сообщений** | Повторно передавать личное сообщение несколько раз, если ACK не пришёл, как это делает reliable router в Meshtastic. |
| **Шрифт UTF-8** | Шрифт дисплея с португальскими, испанскими и русскими глифами и эмодзи, а также ввод не-ASCII с клавиатуры. |
| **Сохранение истории чатов** | Сохранять сообщения между перезагрузками (карта SD или NVS, с ограничением объёма). |
| **Неблокирующая передача** | Передача по прерыванию, чтобы интерфейс оставался отзывчивым в течение до 2.2 с эфирного времени. |
| **Телеметрия / traceroute** | Показывать телеметрию других узлов, отвечать на traceroute и отправлять его. |
| **Индикатор батареи** | Читать АЦП батареи, который v1 не использует. Требует осторожности: источник ВЧ-энтропии, используемый для генерации ключей, делит оборудование с АЦП, поэтому АЦП нужно настраивать после генерации ключей. |
| **MeshCore?** | Поддержка протокола MeshCore как альтернативной mesh-сети. Требует изучения. |
| **Миграция идентичности** | Версионированная миграция записи ключа, чтобы будущая смена формата никогда не приводила к созданию нового ключа. |

## Известные ограничения v1

| Ограничение | Подробности |
|---|---|
| **Текст до 199 байт** | Сообщения, приветствия и строка ввода ограничены 199 байтами UTF-8. |
| **Глифы дисплея** | В шрифте CP437 нет некоторых букв с диакритикой (показываются без неё, например `ã → a`), кириллицы и эмодзи (показываются как `?`). Отправляемый текст никогда не изменяется. См. [руководство пользователя](user-guide.md#ограничения-дисплея). |
| **Клавиатура только ASCII** | Вводить можно только печатные символы ASCII. Символ `` ` `` ввести нельзя (это Esc). |
| **Блокирующая передача замораживает интерфейс** | Пока передаётся кадр (до 2.2 с для 255 байт), клавиши не читаются и экран не обновляется. |
| **Нет автоповтора клавиш** | Удержание клавиши не повторяет её. |
| **Прокрутка на текстовых экранах** | История прокручивается `Fn`+`;` / `Fn`+`.`, по одной строке за нажатие. |
| **Нет повторов личных сообщений** | Личное сообщение без ACK остаётся в `.`. |
| **Сообщения только в RAM** | 30 на переписку, 96 всего, теряются при выключении. |
| **100 узлов в RAM** | Удаляется узел, который слышали давнее всех. Ключ удалённого узла сохраняется, только если это сохранённый контакт по личным сообщениям (до 50). |
| **Набор из 500 поприветствованных** | После 500 поприветствованных узлов автоприветствие перестаёт приветствовать новые узлы, чтобы никто не получил приветствие дважды. |
| **Один канал и один пресет** | Только основной канал по умолчанию, только LongFast. |
| **Нет подписей** | XEdDSA не реализован. См. [security.md](security.md#что-не-защищено). |
| **Нет приложения для телефона, Wi-Fi, BLE и MQTT** | Устройство настраивается только с собственной клавиатуры. |
| **Физическое извлечение ключа** | При установке через M5Launcher шифрование флеш-памяти выключено, поэтому закрытый ключ в NVS можно прочитать при физическом доступе. |
| **Смена региона теряется в течение 2 с** | Смена региона сохраняется через 2 с после последнего изменения или при выходе из Config. Выключение раньше её теряет. |
| **Нет автоопределения Cap во время работы** | Если Cap отсутствовал при запуске (`SEM CAP LoRa`), после исправления прошивку нужно перезапустить. |
| **Экспериментальные регионы** | IN, NZ_865, NP_865, KZ_863, JP, TW и TH лежат за пределами номинального диапазона Cap 868–923 MHz, их характеристики не измерялись. |
| **Полная совместимость ещё не проверена в полевых условиях** | Инициализация радио, передача, сохранение идентичности и интерфейс проверены на устройстве. Обмен личными сообщениями и сообщениями канала с другими узлами Meshtastic реализован и покрыт тестами на векторах, совместимых с основным проектом, но в реальных условиях пока не подтверждён. |
