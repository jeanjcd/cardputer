# Оборудование

M5-Mesh-Hello работает на одной конкретной связке:

- **M5Stack Cardputer-Adv** (ESP32-S3, дисплей 240 × 135, клавиатура за контроллером TCA8418).
- **M5Stack Cap LoRa-1262**: LoRa-трансивер Semtech SX1262, номинальный диапазон 868–923 MHz, до +22 dBm, антенный разъём RP-SMA. На модуле также есть GNSS-приёмник ATGM336H, который v1 не использует.
- **Антенна** на разъёме RP-SMA модуля Cap. Антенна из комплекта настроена на 868 MHz (см. [Антенна и дальность](#антенна-и-дальность)).

Оригинальный Cardputer (не Adv) и другие LoRa-модули не поддерживаются: у них другие распиновка, расширитель ввода-вывода и антенный коммутатор.

> **Никогда не передавайте без антенны.** Прошивка отправляет свой NodeInfo меньше чем через секунду после запуска, поэтому прикручивайте антенну до включения устройства.

## Распиновка

По данным [`src/hw/radio.cpp`](../../src/hw/radio.cpp) и документации M5Stack на Cap LoRa-1262:

| Сигнал | Вывод ESP32-S3 | Примечания |
|---|---|---|
| SX1262 NSS (chip select) | G5 | |
| SX1262 DIO1 (IRQ) | G4 | Прерывание при приёме пакета; уровень также опрашивается |
| SX1262 RESET | G3 | |
| SX1262 BUSY | G6 | |
| SPI SCK | G40 | Общий со слотом microSD |
| SPI MISO | G39 | Общий со слотом microSD |
| SPI MOSI | G14 | Общий со слотом microSD |
| microSD CS | G12 | Устанавливается в **высокий** уровень (карта не выбрана) до запуска радио |
| I²C SDA / SCL (внутренняя шина) | G8 / G9 | Общая для контроллера клавиатуры, IMU и расширителя ввода-вывода Cap |
| Расширитель ввода-вывода PI4IOE5V6408 | адрес I²C `0x43` | Порт **P0** управляет ВЧ-коммутатором антенны |
| UART GNSS (ATGM336H) | ESP RX = G15, ESP TX = G13, 115200 бод | **Не используется в v1** |

Шина LoRa/SD работает на периферийном блоке SPI2 (`FSPI`) ESP32-S3. Дисплей использует SPI3.

## Антенный коммутатор (PI4IOE5V6408, P0)

ВЧ-коммутатор Cap включается через порт P0 расширителя ввода-вывода PI4IOE5V6408 на внутренней шине I²C (адрес `0x43`, 400 kHz). При запуске прошивка:

1. инициализирует расширитель;
2. настраивает P0 как выход, отключает его высокоимпедансный режим и устанавливает **высокий** уровень;
3. считывает обратно регистр выхода.

Cap считается **найденным**, только если все шаги прошли успешно и P0 читается в высоком уровне. Иначе строка состояния показывает `SEM CAP LoRa`. Прошивка всё равно пытается запустить SX1262, но без включённого коммутатора ничего полезного отправить или принять нельзя. Переключение между передачей и приёмом внутри Cap выполняет вывод DIO2 микросхемы SX1262 (поведение RadioLib по умолчанию, как в официальном примере M5Stack).

`M5Cardputer.begin()` должен выполняться до запуска радио, потому что именно он поднимает внутреннюю шину I²C. Расширитель делит эту шину с контроллером клавиатуры и IMU.

## Настройки радио

| Параметр | Значение |
|---|---|
| TCXO | **3.0 V**, регулятор в режиме **LDO** (как в официальном примере M5Stack) |
| Защита от перегрузки по току | 140 mA |
| Усиление RX | Повышенное (boosted), как в Meshtastic, для лучшей чувствительности |
| Модем | LoRa, BW 250 kHz, SF 11, CR 4/5 (Meshtastic LongFast) |
| Sync word | `0x2B` (Meshtastic) |
| Преамбула | 16 символов |
| Заголовок / CRC | Явный заголовок, CRC полезной нагрузки включён |
| Мощность передачи | 2–22 dBm, ограничивается регионом (см. [frequencies.md](frequencies.md#мощность-передачи)) |
| Частота | Вычисляется по региону (см. [frequencies.md](frequencies.md)) |

Приём работает по прерыванию на DIO1. Для надёжности прошивка также проверяет уровень DIO1 на каждом проходе цикла и перезапускает приём после 10 минут без какого-либо RX или TX. Передача блокирующая: главный цикл, а значит и интерфейс, приостанавливается, пока кадр не будет отправлен (до 2.2 с для кадра максимальной длины).

## Общие шины

- **SPI со слотом microSD.** CS карты SD (G12) удерживается в высоком уровне, чтобы карта игнорировала шину, пока ею пользуется радио. Во время работы v1 карту SD не использует. M5Launcher использует её только для установки прошивки.
- **I²C с клавиатурой.** Расширитель антенного коммутатора находится на той же внутренней шине I²C, что и контроллер клавиатуры TCA8418. Прошивка пишет в расширитель один раз, при запуске.

## GNSS (не используется в v1)

На Cap есть GNSS-приёмник ATGM336H на UART (ESP RX = G15, TX = G13, 115200 бод). v1 не запускает UART и не передаёт координаты. Передача местоположения есть в [планах](roadmap.md). M5Stack отмечает, что передачи LoRa мешают GNSS-приёмнику, и v2 придётся это учитывать.

## Антенна и дальность

Антенна из комплекта Cap настроена на **868 MHz**. В регионе 902–928 MHz она всё равно работает, с небольшими потерями:

- 919.875 MHz (ANZ) примерно на 6 % выше частоты настройки, а 903.875 MHz (BR_902) — примерно на 4 % выше. Вдали от частоты настройки КСВ (VSWR) антенны растёт.
- При КСВ 2:1 отражается около 11 % мощности, это потери ≈ **0.5 dB**. При 3:1 — ≈ **1.25 dB**.
- Публичных измерений этой антенны на 915 MHz нет. Рассчитывайте на потери около **0.5–2 dB**, что соответствует примерно 5–20 % дальности. Для больших расстояний это работает, но не идеально.

Что сильнее всего влияет на дальность, по порядку:

1. **Высота и прямая видимость.** Подъём устройства на несколько метров или переход к окну, на балкон или крышу даёт гораздо больше, чем любая смена антенны. Здания, холмы и тела людей блокируют сигналы 900 MHz.
2. **Антенна, настроенная на ваш диапазон.** Для регионов 902–928 MHz (ANZ, BR_902, US, ...) купите антенну, настроенную на **915 MHz**, а не «широкополосную». Для регионов 863–870 MHz (EU_868, RU, ...) подходит комплектная антенна на 868 MHz.
3. **Вертикальная ориентация** — та же поляризация, что у других узлов.
4. **Максимально допустимая мощность.** По умолчанию стоит 22 dBm. Регион может снизить эффективную мощность.

С комплектной антенной на 868 MHz регион BR_902 чуть ближе к её частоте настройки, чем ANZ, но бразильское сообщество работает в ANZ. См. [frequencies.md](frequencies.md#антенны-по-диапазонам).

**Никогда не передавайте без подключённой антенны.** При передаче в открытый разъём мощность отражается обратно в усилитель мощности и может его повредить.

## Установка через M5Launcher

Образы релиза находятся в [`bin/`](../../bin/):

| Файл | Назначение |
|---|---|
| `M5-Mesh-Hello.bin` | Образ приложения. Устанавливается через **M5Launcher** с карты SD. |
| `M5-Mesh-Hello-merged.bin` | Полный образ флеш-памяти (загрузчик + таблица разделов + boot_app0 + приложение) для записи по смещению `0x0` через esptool или веб-прошивальщик. Он **заменяет всё содержимое флеш-памяти, включая M5Launcher и установленные через него приложения**. Используйте его, только если вы не пользуетесь M5Launcher. |
| `SHA256SUMS` | Контрольные суммы SHA-256 обоих образов |

Шаги:

1. Проверьте загрузку: `sha256sum -c SHA256SUMS` в каталоге `bin/` (в Windows: `certutil -hashfile M5-Mesh-Hello.bin SHA256`, затем сравните). См. [security.md](security.md#проверка-релиза).
2. Скопируйте `M5-Mesh-Hello.bin` на карту microSD.
3. В M5Launcher выберите карту SD, выберите файл и установите его.
4. Прикрутите антенну, затем запустите приложение.

Замечания о разделах:

- M5Launcher создаёт раздел приложения по размеру устанавливаемого бинарного файла. v0.1.0 занимает около 590 KiB (603744 байта). Прошивка не использует раздел SPIFFS/LittleFS, и всё, что она хранит, попадает в **NVS** (пространство имён `meshhello`, см. [architecture.md](architecture.md#хранение-nvs)).
- Чтобы установить более новую версию, сначала **удалите старую** в M5Launcher (**PMan → Remove**), затем установите новый бинарный файл. Так раздел освободится, и новый образ получит раздел правильного размера.
- Настройки, пара ключей, список поприветствованных и сохранённые контакты хранятся в NVS и обычно переживают переустановку приложения. Стирает ли M5Launcher NVS, зависит от версии Launcher и выбранных параметров.

**Не запускайте `pio test` на устройстве с установленным M5Launcher.** Механизм запуска тестов PlatformIO на устройстве прошивает собственный образ и затирает M5Launcher и его приложения. Все тесты этого проекта выполняются нативно на ПК (см. [development.md](development.md)).

## Примечание о дисплее

С текущей версией M5GFX поворот 0 на Cardputer-Adv уже соответствует альбомной ориентации (240 × 135). Прошивка никогда не вызывает `setRotation(1)`.
